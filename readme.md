# M30 Instagram Post Automation Pipeline

## Problem

The Minerva University Class of 2030 required a scalable way to collect, format, and publish student spotlight posts on Instagram. Manual coordination of images, captions, and formatting was time-consuming and error-prone.

## Solution

This project implements an automated pipeline that:
- Collects structured student submissions via Google Forms
- Processes and formats images into a consistent branded template
- Generates standardized captions
- Prepares posts for publishing

The system ensures visual consistency, reduces manual editing time, and scales with cohort size
